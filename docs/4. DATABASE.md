## Engine
Supabase project `LABEL-BACKEND` (eu-west-1). One table `public.app_data` (`key` = section name, `value` = jsonb).

## Access
Row-level security: only emails on the staff list read/write (`is_team_member()`). Artists never read `app_data`; they use `artist_portal()` and `artist_add()`. Role permissions are enforced in the app.

## Migrations
`supabase/migrations/`. A data shape change needs a migration of `app_data`; `DATA_VERSION` in `src/seed.js` only reseeds an empty database.
