## Workflow
Read PRODUCT.md and AGENTS.md first; each screen is one file in `src/sections/`; money math only in `src/finance.js`; licence rules in `src/licenses.js`.

## Rules
- **Imports fill in missing song codes.** Every import (EMPIRE statements and the general CSV import) adds a song's ISRC and UPC to the Catalog when the song has none. A code already on a song is never replaced; a different code in the file, or two codes for one song, is flagged in the preview and the summary instead (`catalogCodeFills` in `src/empire.js`). Any new import path must do the same.
