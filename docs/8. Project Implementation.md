## Financial integrity plan (2026-10-20, not started)
Gradual, each step keeping the verified baseline in AGENTS.md and never recalculating published payouts:
1. **Validated records**: a JSON schema per money section (revenue, masterGross, ledger, payouts, invoices) checked in the database on save; reject malformed amounts, months and ids.
2. **Import idempotency**: store each statement file's SHA-256 with its import; refuse the same file twice; revenue row ids already make re-imports replace, not add.
3. **Reconciliation states**: per month, gross received vs tracked (the existing untracked gap) recorded as open/explained/closed with who and why, instead of only computed.
4. **Fixed precision**: store amounts as integer cents (or numeric) alongside the current floats; compute in cents in `finance.js` behind the baseline tests; switch reads once both agree to the cent on all history.
5. **Per-row storage**: move money sections from single JSON values to tables when the above is in place, so row-level policies and per-artist reads become possible.
