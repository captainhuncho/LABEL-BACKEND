# Setup

Summary only. The source of truth is the linked doc; when they disagree, the code wins, then that doc, then this file.

Source: [README.md](../README.md) and [AGENTS.md](../AGENTS.md).

## Prerequisites
Node and npm.

## Install and run
`npm install`, `npm run dev`.

## Environment variables (names only)
`VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY` in `.env.local` (both public). Never put the Supabase service-role key anywhere outside Supabase.
