# Testing & QA

## Tests
Node test runner, `npm test`: finance, EMPIRE parsing, licences, and streams tests.

## Release checks
`npm test` and `npm run build` pass; check the finance baseline (AGENTS.md, Verified baseline) before any change to money math.

Before deploying the paired-save migration, test both allowed pairs under a signed-in role, reject stale versions and unauthorized roles, and confirm that failure on the second update leaves the first section unchanged. Exercise the scheduled publish job once against a test project. The Node tests do not exercise Supabase transactions or Storage uploads.
